Job Search Alert Agent

Scans career pages and job boards on a schedule, filters postings by keyword, location and experience level, and sends a Telegram alert the moment a genuinely new match shows up — so you stop refreshing job boards by hand.

View on GitHub How it works

How it works

  • 1. Configure your sources Point it at any company careers page, or a job board with known result-list selectors (AllJobs, Drushim, etc.).
  • 2. Filter by keyword Only postings matching your target titles get through — with an exclude list for terms like "Senior" when you want junior roles, or vice versa.
  • 3. Optional location & experience checks Skip postings outside your target locations, and flag ones that ask for more years of experience than you want to see.
  • 4. Deduplicated Telegram alerts Every new match is recorded so you're only ever notified once per listing — failed sends are retried automatically on the next run.

Quick start

pip install -r requirements.txt
cp config.example.yaml config.yaml
# edit config.yaml with your Telegram bot token, keywords, and target sites
python Job_agent.py

Schedule it with cron or Windows Task Scheduler to run automatically, e.g. twice a day.
